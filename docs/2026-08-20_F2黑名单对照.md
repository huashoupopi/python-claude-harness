# F2 黑名单对照（合并前）

两份真相源：`permission_hook` 的 `DENY_LIST`，`run_bash` 里的局部 `dangerous`。
`DESTRUCTIVE` 是「问人」不是「直接拒」，不在本合并范围内。

## 逐条

| 模式 | DENY_LIST | dangerous | 语义 |
|---|---|---|---|
| `rm -rf /` | 有 | 有 | 重叠，一致 |
| `sudo` | 有 | 有 | 重叠，一致 |
| `shutdown` | 有 | 有 | 重叠，一致 |
| `reboot` | 有 | 有 | 重叠，一致 |
| `mkfs` | 有 | 无 | 只在 hook |
| `dd if=` | 有 | 无 | 只在 hook |
| `> /dev/sda` | 有 | 无 | 只在 hook；被下一行覆盖 |
| `> /dev/` | 无 | 有 | 只在 run_bash；比 `> /dev/sda` 更宽 |

## 冲突

没有「一份拦、另一份放」的相反语义。`> /dev/` 包含 `> /dev/sda`，并集取两者都不放松。

## 并集（合并后唯一来源）

`rm -rf /` / `sudo` / `shutdown` / `reboot` / `mkfs` / `dd if=` / `> /dev/sda` / `> /dev/`
